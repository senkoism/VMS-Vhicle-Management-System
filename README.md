# Vehicle Management System

A Dart command-line application demonstrating the complete set of **Object-Oriented Programming (OOP)** principles: Class & Object, Constructor, Method, Inheritance, Polymorphism, Encapsulation, Abstraction, and Mixin.

## How to Run

```bash
# 1. Fetch dependencies
dart pub get

# 2. Run the application
dart run bin/main.dart
```
